# 오답 파트 연습과 보상 도전

오답노트는 고대사·고려·조선·개화기·일제강점기·현대사·독도와 간도·종합 파트별로 서버의 실제 고유 문제 수를 표시한다. 맞힌 문제도 등록 목록에 남고 즉시 반복해서 풀 수 있다. 24시간과 1→3→7일 복습 날짜는 재출제를 막지 않는다. 기존 간격·연속 정답 기록은 안내용 정보로 유지한다.

파트 연습은 최대 100문제를 중복 없이 선택하고, 실제 답만 서버에 기록한다. 성장 보상·벌점·하루 도전 횟수는 적용하지 않는다. 기존 20문제·30분 보상 도전은 별도 버튼으로 시작하며 하루 5회 제한과 보상 규칙을 유지한다. 기존 큐와 마감 시각은 다시 들어가도 바뀌지 않는다.

가중치는 `(1 + min(실제 오답 수, 5)) × 최근성 × 노출 보정`이다. 과거 오답·최근 오답·노출 횟수에 따라 선택하며, 실제 오답이 없는 수동 등록은 0회로 표시한다. 수동 등록일은 선택의 최근성 참고값이며 틀린 날짜로 표시하거나 답안 기록을 만들지 않는다.

## 책에서 등록한 개인 오답

마이그레이션 010의 `manual_wrong_notes`는 계정과 문제 ID별 고유 등록이다. 공식 원본과 정답을 확인한 항목만 등록한다. 기존 문제 버전과 공용 분류를 보존한다. 개인 교재 파트는 개인 리뷰의 `part`로 저장해 책의 고대사 묶음을 유지한다. 개인 해설·맞춤 복습은 인증된 본인 API만 반환한다. 공용 파일에는 이메일·사용자 ID·개인 21문제 목록을 넣지 않는다.

`GET /api/v1/wrong-notes/parts`는 전체 및 파트별 수, `GET /api/v1/wrong-notes/focused-review`는 본인의 맞춤 자료를 반환한다. 프리미엄 검사는 서버에서 수행한다. 파트 연습은 `POST /api/v1/wrong-notes/replays`의 `era`로 시작하며, 중복 답 저장은 기존 submission ID로 멱등 처리한다.

## 배포 후 수동 등록 절차

프런트 원본 사진과 API 마이그레이션 010–011을 먼저 기존 배포 경로에 반영한다. 빌드된 `dist/scripts/import-book-wrong-notes.js`를 기존 환경 설정으로 실행한다. 필수 인자는 `--package`, `--source-review`, `--owner-email`, `--front-url`이다. 기본은 전체 트랜잭션 롤백 dry-run이다. `--apply --backup <새로운 비공개 파일>`을 명시할 때만 실제 등록하며, 백업은 0600·새 파일 생성으로 제한한다.

도구는 공식 검증 패키지와 원본 검증 파일 SHA256, 배포 이미지 SHA256, 단일 계정, 기존 문제 ID·버전·정답을 확인한다. 계정 행 잠금 안에서 관련 문제·등록·보호 이력을 백업하고 등록한다. 실제 답·성장·시험·CBT·출석 이력의 전후 지문이 같아야 커밋한다. 중복 실행은 등록을 추가하거나 기존 등록을 덮어쓰지 않는다. 자격 증명과 개인 자료는 로그에 출력하지 않는다. 원격 인증이나 배포가 막혀 있으면 운영 등록도 보류한다.
