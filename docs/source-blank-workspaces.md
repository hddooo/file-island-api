# 원문 빈칸의 묶음·수정 가능한 계정 저장

`GET/PUT /api/v1/textbook/semantic/workspaces/:id`는 기존 교재 회원 가드와 `private, no-store`를 사용한다. 사용자 ID는 JWT에서만 받는다. 새 migration018은 전용 `hanq.source_blank_workspaces` 테이블 하나만 추가한다. 원래 source_blank_progress와 시험·오답·성장 기록은 수정하지 않는다. 기존 migration 체크섬/잠금/권한 회수·서버 시작 순서를 따른다.

새 행이 없으면 기존 순차 진행의 답과 현재 초안을 읽기 변환한다. 첫 v2 저장도 원래 행을 보존한다. 원문 전체 데이터의 지문과 기존 quiz ID를 저장 키로 사용해 원문 변경 시 이전 버전 행을 덮어쓰지 않는다.

workspace는 문항별 입력 배열, 확인한 답칸 마스크, 서버 판정, 현재 문항 위치와 중단 상태를 보관한다. PUT은 변경한 문항만 묶어서 받는다. 원문 문항 ID·슬롯 개수·길이·중복 ID·커서를 검증한다. 정답 판정은 서버의 기존 정확 비교 규칙으로 계산하며 클라이언트의 correct 필드를 받지 않는다. 원문의 공백/NFC·복수답 순서·순서형 기호만 인정하고 동의어나 유사답은 추가하지 않는다.

트랜잭션 잠금, revision과 mutationId/hash로 오래된 저장을 거부한다. 직전 같은 요청은 같은 결과를 반환하고 다른 내용으로 재사용한 키는 거부한다. 계정별 쿼리는 모두 user_id를 포함한다. 원문/정답/운영 시험 테이블의 데이터 삭제나 백필은 없다.

검증은 새 임시 loopback 테스트 DB에서 수행한다. 기존 계정 진행을 만든 뒤 v2 읽기·수정을 하고 원래 행이 같은지 확인한다. 두 계정 격리·JWT 로그아웃/재로그인·잘못된 사용자/판정 필드 거부·동시 요청 충돌·동일 요청 재시도를 검사한다. 원문642문항의 정확 정답/명확한 오답·수정/초안 저장은 순수 전이 검사로 확인한다. 운영 DB에 검증용 답을 쓰지 않는다.
