# 공개 원본 이미지로 기존 Render CBT 배포

사용자는 2026-10-12에 원본 문제 이미지 공개를 승인했다. 대상은70~79회 원본 문제500개와72회 공통 자료1개다. 정답·채점키·개인기록 공개가 아니다. 새 호스팅이나 유료 디스크를 추가하지 않는다.

## 배포 대상과 순서

1. 기존 프런트 저장소 hanq_front/dev의 변경을 기존 GitHub origin에 사용자가 반영·배포한다. 공개 파일은 media/cbt-originals/70-01.webp~79-50.webp, 72-common47-48.webp 및 manifest.json이다. 합계 약40.08MB이며 manifest에는 파일명과SHA만 있다. 기존 Vercel 배포에서 해당 파일은 제외되지 않는다.
2. 기존 API 저장소 hanq_api/dev의 변경을 기존 origin에 사용자가 반영·배포한다. API의 기본 원본 URL은 https://hanq.vercel.app/media/cbt-originals 이므로 Render 디스크나 HANQ_CBT_ASSET_DIR 없이 동작한다. 기존 JWT/DB/CORS 설정은 유지한다.
3. 새 브라우저에서 로그인→79회→시작→첫 원본 문제→전체50문항→제출을 확인한다. 10회차 모두 실제 배포된 이미지와 해시 검사가 성공하면 활성화된다. 자산을79회만 배포하는 경우에는79회만 활성화되고 나머지는 준비 중으로 남는다.

API는 공개 이미지 원본을 인증된 기존 이미지 API를 통해 전달하며, 서버의 시험/채점/기록 인증은 유지한다. 공개 정적 주소 자체에서는 사용자가 승인한 대로 원본 이미지가 로그인 없이 보인다. 기존 비공개 디렉터리가 유효하면 사용할 수 있지만 파일이 없으면 승인된 공개 원본으로 전환한다. 원본 이미지 검사 전에 시계를 시작하지 않는다.

## 준비 상태와 검증

목록은 문항/정답/배점 구조와 모든 원본 이미지의WebP 형식·크기·SHA를 검사한 회차만available:true로 반환한다. 공통 자료도 검사한다. 한 회차의 누락/손상은 그 회차를 비활성화한다. 시작 때도 전체 이미지를 다시 확인한다. 목록은 기록을 생성/초기화하지 않는다.

공개 manifest는5초 이내에 갱신되며 정답은 포함하지 않는다. 원본 검사에는4개씩 병렬 요청과12초 전체 예산을 적용하고 각 배치의 완료를 기다린다. CDN이 응답하지 않으면 준비 중으로 남고 시험 시간은 시작하지 않는다. 파일 크기8MB/manifest1MB 상한, 리다이렉트 금지,10초 개별 요청 제한을 적용한다.

기본 URL을 바꾸는 경우에만 HANQ_CBT_PUBLIC_ASSET_BASE_URL을 설정한다. 현재 기존 호스트를 사용할 때는 설정할 필요가 없다. localhost HTTP는 격리 테스트에서만 허용된다. off는 공개 원본을 끄고 기존 비공개 전용으로 쓰는 선택값이다.

운영 설치·배포·첫 문제 표시는 아직 직접 검증하지 않았다. 로컬 커밋만으로 운영이 바뀌지는 않는다. 현재 작업에서는 push/운영 배포를 수행하지 않는다.

## 추가 비용 없는 구조의 근거

Render 기본/Free 파일시스템의 런타임 변경은 재배포·재시작·슬립 때 사라진다. 공개 원본은 기존 Vercel 프런트의 배포 산출물에 포함하므로 Render 로컬 파일 설치가 필요 없다. 기존 서비스의 실제 플랜/청구 조건은 관리자 화면에서 확인되지 않았다. 전체 원본을Render Secret Files에 넣는 방안은 합계1MB 제한에 맞지 않는다.
